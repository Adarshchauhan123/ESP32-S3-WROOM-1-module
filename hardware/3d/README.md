# 3D CAD Assets

Recommended files for this folder:

```text
HEAD_PCB_3D.glb     # web viewer
HEAD_PCB_3D.step    # mechanical CAD exchange
HEAD_PCB_3D.stl     # generic triangulated mesh
```

The GLB model can be embedded in a browser portfolio page. The STEP file is the preferred format for mechanical CAD/enclosure integration.

The exported board envelope from the provided STEP model is approximately **73.98 mm × 58.73 mm × 16.10 mm**.
