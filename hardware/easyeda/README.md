# EasyEDA Pro Source

Place the exported EasyEDA Pro project archive in this folder as:

```text
HEAD_PCB.epro2
```

The project can then be imported in EasyEDA Pro using the Professional-project import option.

## Expected project contents

The source project contains the HEAD PCB schematic and PCB layout built around the ESP32-S3-WROOM-1 module.

## Import

1. Open EasyEDA Pro.
2. Select **Import Professional / EasyEDA Pro project**.
3. Choose `HEAD_PCB.epro2`.
4. Import into your Personal workspace.
5. Open the schematic and PCB documents.

> The binary `.epro2` archive should be kept unchanged; do not manually edit the archive contents.
