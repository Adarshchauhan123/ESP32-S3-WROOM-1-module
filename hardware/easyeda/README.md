# EasyEDA Pro Source

The editable EasyEDA Pro project for the HEAD PCB is included in this folder:

[`HEAD_PCB.epro2`](HEAD_PCB.epro2)

The archive contains the project schematic and PCB layout for the ESP32-S3-WROOM-1 based HEAD controller.

## Import

1. Open EasyEDA Pro.
2. Select **Import Professional / EasyEDA Pro project**.
3. Choose `HEAD_PCB.epro2`.
4. Import it into your workspace.
5. Open the schematic and PCB documents.

> Keep the `.epro2` archive unchanged; it is the native editable project source.
